# Data Structures and Algorithms Using C++

## Project Overview
An individual academic project developed using C++ as part of the Data Structures and Algorithms course during the second academic level of the Information Technology program.

The project focuses on the practical implementation of fundamental data structures to understand how data is organized, stored, accessed, and processed. It demonstrates different approaches to data management and explores the characteristics and operations of each data structure.

## Project Objectives
- Apply theoretical concepts of data structures using C++.
- Understand how different data structures organize and manage data.
- Explore the characteristics and operations of each data structure.
- Gain practical experience in implementing data structures.
- Understand how to choose appropriate data structures based on their intended use.

## Concepts and Features

The project covers the following concepts:

- **Arrays:** Organizing elements and accessing them using indexes.
- **Classes:** Organizing data and functions using object-oriented programming principles.
- **Graphs:** Representing relationships and connections between elements.
- **Linked Lists:** Organizing elements through links between nodes.
- **Queues:** Managing elements using the First In, First Out (FIFO) principle.
- **Stacks:** Managing elements using the Last In, First Out (LIFO) principle.
- **Trees:** Representing data in a hierarchical structure.
